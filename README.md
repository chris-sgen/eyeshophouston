# eyeshophouston

> **Unofficial copy — not the website of Eye Shop.** This repository is a development copy of
> a redesign, published so that the redesign can be looked at in a browser. It is not operated by, affiliated with, or endorsed by
> Eye Shop. The practice's real site is https://www.eyeshophouston.com/.
>
> **A snapshot, and none of the practice's forms sends anything here.** The pages were read from the practice's site on the evening of October 20, 2026, Houston time (October 20, between 23:37 and 23:45 UTC), and are
> not kept current. The practice's three forms (the appointment request, the contact form and the patient registration form) are disabled in this copy: each of those pages says that this preview is not the practice's website and that its form is disabled, and gives the practice's telephone number.

**Preview: https://chris-sgen.github.io/eyeshophouston/**

A **redesign** of **eyeshophouston.com** (Eye Shop, an eye care practice in Houston, Texas): 148 pages, made by a rebuild pipeline and changed for public hosting as listed under *Hardening*: the 146 pages of the live site that the crawl found, at their own addresses, and a search page and a not-found page that the build makes itself. It is a static site with no backend. To look at it, use the preview link. To serve the folder yourself, use a server that answers a folder's address (`/insurance/`) with the `index.html` inside it, under the path `/eyeshophouston/` (the not-found page names its files there).

> **6 still pictures and 1 silent video loop in this copy are AI-generated illustrations made for this redesign.**
> They are not photographs of the practice, its office, its doctors or its staff, and none shows a person (see *Generated imagery*).
> **The photographs of the practice's own people are not shown here** (Hardening 6).

Two terms used below. The **private build** is the build of this redesign that this copy was made from,
with its documentation and audit files; it is not published. This **preview** is that build with the
changes listed under *Hardening*.

## Hardening applied to this public copy

`PROVENANCE.json` gives the counts.

1. **`noindex, nofollow, noarchive, nosnippet, noimageindex` on every page.** This tag is the only index control this copy has. It is a request, not a lock: the large search engines say they follow `noindex`; `noimageindex` is a rule of Google's. A `robots.txt` with `Disallow: /` is also shipped, but it has **no effect** here: crawlers read `robots.txt` only at the host root (`chris-sgen.github.io/robots.txt`, which only a separate repository for that host could provide), not under `/eyeshophouston/`. GitHub Pages cannot send an `X-Robots-Tag` header either. That leaves every file that is not a page (the pictures, the loop, the fonts, the stylesheets, the script, the search index, the licence texts and these documents) with no index control of its own; on this site they are linked only from pages marked `nofollow`. The repository itself is public: github.com lists every file of it, and its page there can be indexed.
2. **Link-preview tags.** `og:url` points at this preview, `og:description` / `twitter:description` carry the disclosure, `og:site_name` reads "Unofficial preview (not Eye Shop)", and `og:title` / `twitter:title` begin "Unofficial preview:" (148 pages), with the practice's name taken off where it stands at the end of the title after a bar ("… | Eye Shop", "… | Eye Shop in Houston, TX"); a title that names the practice inside its own words keeps them. The picture tags (`og:image`, `twitter:image`: 296 tags) are removed and `twitter:card` is `summary`, the small card, so no tag offers a picture. The practice's icon is not this copy's tab or home-screen icon (296 icon links removed; an empty icon stands in). **The `<title>` of a page is not marked**: it is the private build's title. What a link card shows depends on the app: apps that take a link's description or site name from these tags show the disclosure; apps that read none of these tags show the page's own title with the `chris-sgen.github.io` address; apps that pick a picture from the page itself may show one of its pictures.
3. **JSON-LD removed** (1,195 blocks). It asserted, as data for search engines, the practice's identity, address, telephone and opening hours, and the trail and kind of each page.
4. `<meta name="referrer" content="no-referrer">` on every page, so a click on an outbound link does not tell its target this address. The 148 map frames carry `referrerpolicy="no-referrer"` themselves, because a policy on a frame overrules the page's. No page holds a film (see 7); the script's code for a film frame (unused here) would send only this site's bare origin.
5. **The practice's three forms are disabled, with or without JavaScript** (`/contact-us/appointment-request-form/`, `/contact-us/contact-form/`, `/contact-us/patient-registration-form/`). Three safeguards are layered:
    - **A hidden, disabled submit button is placed first in each form**, followed by a hidden, disabled text field. A form whose default button is disabled is not submitted when Enter is pressed in it; a browser that skips a disabled button decides by counting the form's single-line fields, and the hidden field keeps that count above one (that second case was not tested here: only Chrome was run).
    - The **submit button is replaced by a disabled `type="button"`**.
    - Each form gets `action=""`, `onsubmit="return false"`, `method="dialog"` and `data-preview="inert"`, and the hooks by which the private build's script finds a form are removed, so that script does not touch it at all.

    A note in the head of each of those pages says that this preview is not the practice's website, that the form on the page is disabled and that nothing entered in it is sent or saved by this copy, and gives the practice's telephone number; a shorter line right above the form and a line under its button say it again. The fields can still be typed in; nothing typed leaves the browser. **The site search still works**: its 152 forms send the words only to this copy's own `/search/` page, as part of that page's address. **The 2 boxes that ask Google Maps for directions are not offered** (`/hablamos-espanol-doctor-de-los-ojos-en-west-houston-tx/` and `/hablamos-espanol-doctor-de-los-ojos-en-west-houston-tx/monturas-de-diseno-en-west-houston-tx/`, pages written in Spanish): on the live site they send the starting address a visitor types, and a destination the box keeps hidden ("West Houston Eye 10260 Westheimer Rd, Ste 550, Houston, Texas 77042"), to Google Maps, while the rest of the site gives the address 13130 Memorial Drive. In the place of each box (its label, its field and its button) a note in Spanish says that the box is not offered, names that destination, says that most pages of the site give 13130 Memorial Drive and links to the live page. On a phone the private build folds shut the section of `/hablamos-espanol-doctor-de-los-ojos-en-west-houston-tx/monturas-de-diseno-en-west-houston-tx/` that holds the box; here that section stays open, so the note is read where the box stood.

## Known limits
